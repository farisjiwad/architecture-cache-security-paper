# architecture-cache-security-paper

The manuscript follows the supplied APA 6th edition sample. It uses 12-point
Times New Roman, the `apa6` manuscript class, and `apacite` author-date citations.
Bibliographic source data is maintained in `References.bib`.

Build with TeX Live (including XeLaTeX and BibTeX) and Times New Roman installed:

```sh
latexmk Paper.tex
```

The local latexmk configuration selects XeLaTeX. The output is `Paper.pdf`.
